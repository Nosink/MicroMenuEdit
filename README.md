# MicroMenuEdit

Customize the micro menu buttons, border, performance bar, scale, and padding.

## Features

- Show or hide individual micro menu buttons.
- Toggle the micro menu border and performance bar.
- Adjust the overall scale and button spacing.
- Localized settings and tooltips for all supported game locales.

## Configuration

Open the settings panel with either slash command:

```text
/micromenuedit
/mme
```
