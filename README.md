# MicroMenuEdit

MicroMenuEdit is a World of Warcraft addon that lets you customize the micro menu.

## Features

- Show or hide individual micro menu buttons.
- Toggle the micro menu border.
- Show or hide the performance bar.
- Change the micro menu scale.
- Localized settings and tooltips for all supported game locales.

## Configuration

Open the settings panel with either slash command:

```/micromenuedit```
```/mme```
