# MicroMenuEdit

MicroMenuEdit is a World of Warcraft addon that lets you customize the micro menu.

## Features

- Show or hide individual micro menu buttons.
- Toggle the micro menu border.
- Show or hide the performance bar.
- Change the micro menu scale.
- Use the player portrait as the character button icon.
- Localized settings and tooltips for all supported game locales.

## Installation

1. Download or clone this repository.
2. Copy the `MicroMenuEdit` folder into your World of Warcraft `_retail_/Interface/AddOns` directory.
3. Ensure the addon is enabled from the AddOns menu.

## Configuration

Open the settings panel with either slash command:

```text
/micromenuedit
/mme
```

The settings panel can also be opened through the standard AddOns settings interface.

## Slash commands

| Command | Description |
| --- | --- |
| `/micromenuedit` | Open the settings panel |
| `/mme` | Open the settings panel |
| `/mme version` | Display the addon version |
